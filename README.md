**Personal Portfolio Website**

**Project Description**

A responsive personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my profile, skills, projects, and contact information in a simple and professional layout.

**Technologies Used**

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

**Features**

- Home Section: Introduces me and my professional interests.
- About Section: Provides information about me and my background.
- Skills Section: Displays my technical skills.
- Projects Section: Showcases my projects and work.
- Contact Section: Provides contact information.
- Responsive Design: Adapts to different screen sizes, including mobile phones, tablets, and desktops.

**Project Structure**

Personal-Portfolio-Website/
│
├── index.html
├── style.css
├── script.js
└── README.md

**How to Run the Project**

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html".
4. Right-click the file and select Open with Live Server.
5. The portfolio website will open in your web browser.
